Patch screen

SELECTmove the cursor, jack to jack (fast turn: module to module; GLO + SELECT: module to module always)
KNOB 1–4parameters of the module under the cursor (GLO held: fine)
ALGORITHMnext page of knobs
SELgrab a cable at the cursor; turn to another jack; SEL plugs it in. On a group's box with a cable in hand, SEL opens the group (the cable goes in with you)
GLO + SELpick up the cable plugged in at the cursor
GLO + KNOB 1tempo
GLO + PRESETSmetronome: turn up on, down off (the bottom strip shows ON / OFF; MET in the top bar; any page but the patch list)
GLO + HOMEkeys play notes / are the BUTTON modules'
RECtap: unplug one cable of the jack (the oldest first) / drop the cable. Hold: delete the module (reconnects its neighbours if AUTO-REPATCH is on)
GLO + REC (hold)delete the module and wire its cables through, whatever AUTO-REPATCH says
FXadd a module at the cursor (a strip shows where it would go)
SEL (in the add list)add the module unconnected
K1–4 (in the add list)list, category, favorites, recents
in the add listREC makes a module a favorite (*, kept after restart); KNOB 3 steps round the favorites (*); KNOB 4 steps round the last six added (R); KNOB 2 next category; ALGORITHM turns the pages (what it is, example, picture)
GLO + OP1–OP4add favorite 1–4 at the cursor (patch screen)
EDITthe module page (visualization, all parameters)
REC (SAMPLER page)arm, record IN into its RAM (1 s), stop; SAVE keeps it

Signal levels

Audio is ±5 V, and the output module scales 5 V to full scale. Pitch is 1 V per octave with 0 V at C4 (261.6 Hz); filter cutoff tracks it too. Gates and triggers are 0 / 5 V: a rising edge above 1 V starts one, and it is released below 0.5 V. Plug several cables into one input and they add, so you rarely need a mixer for CV.
