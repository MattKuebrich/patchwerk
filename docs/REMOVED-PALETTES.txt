REMOVED PALETTES (rc176): DEFAULT, CMYK and MIDCENTURY.

To bring one back (app/core/pw_ui.c):
 1. Paste its row into pals[] and its name into pal_name[] at the same place (the two lists are in the same order).
 2. Add its old number to pal_id[] at that place (DEFAULT 0, CMYK 1, MIDCENTURY 6), and raise PAL_COUNT by one.
 3. web/page.html: raise the count in palCombos (p < 12) and its comment, and add the name to the palette editor's list (NAMES), in the same place.
 4. If it comes back first (DEFAULT), PW_PAL_DEFAULT (RISO's row) goes up by one for each row put before it.
Units that saved one of these palettes show RISO now; once it is back, a saved choice of its number points to it again.

In the web palette editor: untick "Show the screens as the unit's panel does" before Load from code, so the colors load as they are (these are the unit's own values, already what the screen is given).
